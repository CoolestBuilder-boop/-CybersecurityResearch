# Citing this work

## Plain text

Quigg, D. (2026). *ResearchProjectTemplate*. https://github.com/dstroy0/ResearchProjectTemplate

## BibTeX

```bibtex
@misc{quigg2026researchprojecttemplate,
  author       = {Quigg, Douglas},
  title        = {ResearchProjectTemplate},
  year         = {2026},
  howpublished = {\url{https://github.com/dstroy0/ResearchProjectTemplate}}
}
```

## A specific version

To cite a specific state of the work, name the commit or the release tag beside the URL. A release on GitHub is the stable form.
